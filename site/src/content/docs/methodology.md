## Who maintains this

This directory is maintained by Olexander Paladiy, who works at Coupler.io. Coupler.io is one of the
services listed here and is compared using the same fields as every other option. The directory is
not affiliated with Anthropic.

## What it covers

Each guide answers one question: how can the data in a given business source be analysed in Claude?
A route is included when it moves or exposes that source's data to Claude, whether through a native
connector, an MCP server, a data platform, an automation tool, or a manual file export.

Coverage is not exhaustive. A route appears once it has been checked against the sources cited on
the page.

## How options are ordered

Routes are listed in this order: those maintained by the source vendor or Anthropic, other managed
routes alphabetically by provider, community-maintained routes, and manual export. Routes that are
not currently available are listed after those you can use today. Position in the table is not a
ranking.

## What verified means

- **Verified.** A person checked the claim against the evidence cited on the page, on the date shown.
- **Not verified.** The claim has not been checked yet. This is not the same as "no".
- **Not applicable.** The field does not apply to that route.

Documentation review and hands-on testing are recorded separately, and a page says which one
happened. Pages show a "Review overdue" label when the last review is more than 90 days old.

## The public dataset

The guides are also available as a JSON dataset at [`/connectors.json`](/connectors.json).

## Corrections

If something is wrong, out of date, or missing a caveat, please report it. Each guide links to a
prefilled correction issue for that source.
